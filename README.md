# Python Curriculum

## Overview

This folder contains a set of Python modules that introduce programming concepts in a gradual way, from basic syntax and control flow to more advanced topics such as functions, classes, exceptions, file handling, modules, and decorators.

Each module is organized into exercises that focus on a specific topic. The exercises are meant to be completed in order so each step builds on the previous one.

## Folder Structure

- `python00/` - first Python exercises and introductory syntax
- `python01/` - object-oriented programming basics
- `python02/` - exception handling fundamentals
- `python03/` - exception handling practice and control flow
- `python04/` - file handling and stream management
- `python05/` - stream processing and simple pipelines
- `python06/` - modules, imports, and package organization
- `python07/` - advanced Python concepts and project structure
- `python08/` - additional Python practice exercises
- `python09/` - additional Python practice exercises
- `python10/` - functional programming and decorators

## How to Use

Open the module you want to work on and follow its README file if it exists. Each exercise is usually placed in its own directory and can be run directly with Python 3.

## Notes

- The exercises are written in Python.
- Standard library solutions are preferred unless a module explicitly allows something else.
- No emojis are used in this documentation.
