# python module00

## Project Overview

Module 00 is an introduction to Python syntax and basic programming concepts. The exercises focus on simple scripts, basic calculations, string formatting, variables, loops, and list handling.

The goal of this module is to help you become comfortable with:

- running a Python script
- storing and updating values
- using basic operators
- writing simple loops
- working with lists and indexing
- producing clear output

## Exercise Breakdown

### Exercise 0 - Hello Garden

File: ft_hello_garden.py

Concepts:
- script execution
- print()
- basic output

Objective:
Create a simple program that prints an introductory message.

### Exercise 1 - Plot Area

File: ft_plot_area.py

Concepts:
- variables
- arithmetic operations
- multiplication

Objective:
Compute the area of a garden plot from its dimensions.

### Exercise 2 - Harvest Total

File: ft_harvest_total.py

Concepts:
- numeric calculations
- accumulation
- basic expressions

Objective:
Calculate a total harvest amount from several values.

### Exercise 3 - Plant Age

File: ft_plant_age.py

Concepts:
- date or age conversion
- arithmetic logic
- formatted output

Objective:
Work with age-related values and present the result clearly.

### Exercise 4 - Water Reminder

File: ft_water_reminder.py

Concepts:
- conditions
- simple logic
- reminder messages

Objective:
Display a reminder based on watering-related input.

### Exercise 5 - Count Harvest

Files:
- ft_count_harvest_iterative.py
- ft_count_harvest_recursive.py

Concepts:
- loops
- recursion
- repeated computation

Objective:
Count harvest values using two different approaches.

### Exercise 6 - Garden Summary

File: ft_garden_summary.py

Concepts:

### Exercise 7 - Seed Inventory
