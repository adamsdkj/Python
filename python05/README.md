# Code Nexus - Module 05

## Description
This module is part of the 42 curriculum by adadra and focuses on advanced Python concepts such as polymorphism, type annotations, and enterprise-level data processing pipelines. The exercises simulate real-world scenarios involving data streams, processing pipelines, and integration systems, providing hands-on experience with object-oriented programming and protocol-based design.

### Exercises Overview
- **ex0/stream_processor.py**: Implements foundational data processors using abstract base classes and polymorphism for numeric, text, and log data.
- **ex1/data_stream.py**: Develops polymorphic data streams for sensors, transactions, and events, with batch processing, filtering, and statistics.
- **ex2/nexus_pipeline.py**: Integrates multiple processing pipelines using protocols and abstract base classes, demonstrating enterprise-level pipeline management and error recovery.

## Learning Outcomes
- Master polymorphism and method overriding in Python.
- Apply type annotations and static type checking.
- Use abstract base classes and protocols for extensible design.
- Build modular, testable, and scalable data processing systems.
- Simulate complex, real-world data integration scenarios.

## Instructions
1. Clone or download the repository to your local machine.
2. Navigate to the module directory:
   ```zsh
   cd /home/adadra/core/python/module05
   ```
3. For each exercise, run the script using:
   ```zsh
   python3 exN/<script_name>.py
   ```
   Replace `N` and `<script_name>` with the appropriate values (e.g., `ex0/stream_processor.py`).
4. Ensure all dependencies are installed (Python 3.10+ recommended).
5. Review the output and experiment with modifying the code to observe polymorphic and type-checked behavior.
