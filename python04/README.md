# Cyber Archives Module 04

## Description
This module contains a series of exercises designed to practice file handling, error management, and stream operations in Python. Each exercise simulates a scenario related to cyber archives, preservation, communication, security, and crisis response. The project is part of the 42 curriculum by adadra.

### Exercises Overview
- **ex0/ft_ancient_text.py**: Recovers and displays ancient data fragments from a file, demonstrating basic file reading and exception handling.
- **ex1/ft_archive_creation.py**: Creates and preserves new archive entries, showcasing file writing and reading operations.
- **ex2/ft_stream_management.py**: Manages communication streams, using standard and error output, and handling user input.
- **ex3/ft_vault_security.py**: Simulates secure vault operations, including classified data extraction and protocol archiving.
- **ex4/ft_crisis_response.py**: Handles crisis scenarios with robust error management and system status reporting.

## Learning Outcomes
- Understand and implement file I/O operations in Python.
- Apply exception handling for robust code.
- Use standard input/output and error streams.
- Structure Python scripts for modularity and clarity.
- Simulate real-world scenarios for data management and security.

## Instructions
1. Clone or download the repository to your local machine.
2. Navigate to the module directory:
   ```zsh
   cd /home/adadra/core/python/module04
   ```
3. For each exercise, run the script using:
   ```zsh
   python3 exN/ft_<exercise_name>.py
   ```
   Replace `N` and `<exercise_name>` with the appropriate values.
4. Ensure any required data files (e.g., `ancient_fragment.txt`, `new_discovery.txt`, etc.) are present in the same directory as the script.
5. Review the output and experiment with modifying input files to observe error handling and data processing.
